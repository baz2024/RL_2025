
# 📝 Exercise: Solving the Emergency Room Simulation using Value Iteration and Policy Iteration

## 🎯 Objective

You are tasked with designing a policy to manage patient treatment in a simulated emergency room using **Dynamic Programming** techniques — specifically **Value Iteration** and **Policy Iteration**.

---

## 🏥 Environment Summary

You will use the `RealisticEmergencyRoomEnv` class provided in the notebook.

- **State**: `[mild, moderate, critical, time]`
- **Actions**:  
  `0 = treat mild`  
  `1 = treat moderate`  
  `2 = treat critical`  
  `3 = idle`
- **Goal**: Maximize cumulative reward while minimizing patient deaths and idle time.

---

## 📚 Task Instructions

### Part A: Discretization and State Encoding

1. **Create a function** that maps the environment’s state `[mild, moderate, critical, time]` to a unique integer or tuple state key (e.g., a string or a tuple).
2. Limit patient count to a small range (e.g., 0–3 for each type) and discretize time (e.g., every 5 units).

---

### Part B: Implement Value Iteration

3. Using the Bellman equation, **implement Value Iteration**:
   - Initialize state-value function `V(s)` arbitrarily.
   - Iteratively update values until convergence.
   - Derive the optimal policy π* from the final value function.

---

### Part C: Implement Policy Iteration

4. Implement the **Policy Iteration** algorithm:
   - Initialize with a random policy.
   - Repeat **policy evaluation** and **policy improvement** until the policy is stable.

---

### Part D: Evaluation

5. **Simulate** the environment using the learned policy for several episodes.
6. **Compare performance** (total reward, patient deaths, idle time) between:
   - Your **Value Iteration policy**
   - Your **Policy Iteration policy**
   - The baseline **heuristic agent**

---

## ✅ Deliverables

- Python functions for `value_iteration()` and `policy_iteration()`
- A report/summary markdown or notebook cell including:
  - Number of iterations to converge
  - Cumulative reward
  - Key differences between the policies
