Which of the following best distinguishes Reinforcement Learning (RL) from Supervised Learning? (Question 1)
A. RL uses delayed rewards while Supervised Learning uses immediate and labeled feedback.
B. RL uses labeled data while Supervised Learning does not.
C. Supervised Learning optimizes cumulative rewards.
D. RL cannot operate in dynamic environments.
ANSWER: A

What is the primary role of the agent in Reinforcement Learning? (Question 2)
A. To define the environment.
B. To maximize cumulative rewards through interactions.
C. To provide feedback to the environment.
D. To observe only the current reward.
ANSWER: B

What is the main purpose of the Bellman Equation in reinforcement learning? (Question 3)
A. To calculate gradients for neural networks.
B. To determine policy randomness.
C. To recursively estimate the value of states or state-action pairs.
D. To initialize Q-values arbitrarily.
ANSWER: C

Why is balancing exploration and exploitation important in RL? (Question 4)
A. Because exploration reduces the model accuracy.
B. To avoid infinite loops during training.
C. To ensure the agent gathers information while maximizing rewards.
D. Because exploitation avoids computational cost.
ANSWER: C

Which of the following is a limitation of Monte Carlo methods in RL? (Question 5)
A. They cannot estimate value functions.
B. They require knowledge of model dynamics.
C. They are not suitable for continuous or non-episodic tasks.
D. They rely on the Bellman equation for updates.
ANSWER: C

What distinguishes the SARSA algorithm from Q-Learning? (Question 6)
A. SARSA is an off-policy algorithm while Q-Learning is on-policy.
B. Q-Learning updates the policy with exploration, SARSA does not.
C. SARSA updates using the next action from the same policy; Q-Learning uses greedy action for update.
D. Q-Learning does not use a reward function.
ANSWER: C

Which of the following is a key benefit of Temporal Difference (TD) learning? (Question 7)
A. It requires full knowledge of the environment's transition probabilities.
B. It only works in episodic environments.
C. It combines advantages of both DP and Monte Carlo methods.
D. It avoids bootstrapping.
ANSWER: C
